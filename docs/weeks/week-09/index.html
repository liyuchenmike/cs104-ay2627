Week 09 · Mathematical induction

How can a base case and a valid step prove infinitely many claims?

Prove formulas and divisibility with induction, diagnose flawed arguments, and handle statements that depend on several earlier cases.

  • state the base and step for ordinary induction;
  • prove arithmetic, geometric and square-sum identities;

1 · The base and the link

Induction proves a whole chain of statements

For each positive integer n, let P(n) be a precise statement. Ordinary mathematical induction needs two separate proofs: P(1) is true, and for every k ≥ 1, P(k) implies P(k + 1). The first establishes a starting point; the second links each reachable integer to its successor.

P(1)   ·   ∀k ≥ 1, P(k) ⇒ P(k + 1)
Therefore ∀n ≥ 1, P(n).

The ladder analogy

Knowing how to step from rung k to rung k + 1 does not put you on the ladder. You must first reach rung 1. Then the step rule takes you to 2, 3, and every later rung. In a written proof, state the target P(n), verify its first allowed value, assume P(k) for an arbitrary allowed k, and derive P(k + 1).

If the theorem begins at n = 0 or n = 3, use that value as the base and apply the step only for k at or above it. The induction hypothesis is a temporary assumption in the conditional step, not a claim that has already been proved for every k.

One half of induction is never enough

The base alone proves one case. The step alone can be true even when every P(n) is false. Check both, and check that the step reaches the very next integer in the claimed range.

2 · Follow the extra term

Prove sum formulas by extending the list

To prove the arithmetic sum, set P(n): 1 + 2 + ⋯ + n = n(n + 1)/2 for n ≥ 1. At n = 1, both sides equal 1. If the formula holds through k, append the one new term k + 1:

1 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1)
= (k + 1)(k + 2)/2.

That last expression is exactly the claimed formula with n replaced by k + 1. The move is reusable: separate the old sum from its new term, substitute the induction hypothesis once, then simplify to the target.

Geometric sum starts at zero

For n ≥ 0 and r ≠ 1, let G(n): 1 + r + ⋯ + rⁿ = (rⁿ⁺¹ − 1)/(r − 1). At n = 0, both sides are 1. Assuming G(k), append rᵏ⁺¹:

(rᵏ⁺¹ − 1)/(r − 1) + rᵏ⁺¹ = (rᵏ⁺² − 1)/(r − 1), which is G(k + 1).

When r = 1, the fraction is undefined. The sum itself still exists and has n + 1 terms, so its value is n + 1. This condition must be stated before using the displayed fraction.

Match the base to the index

The geometric sum begins at n = 0, while the arithmetic sum begins at n = 1. Copying the other proof's base would leave the first claimed case unchecked.

3 · A longer algebra step

Sum the first n squares

1² + 2² + ⋯ + n² = n(n + 1)(2n + 1)/6   (n ≥ 1)

The base n = 1 gives 1 on both sides. For the induction step, do not replace the new square with the hypothesis: the hypothesis covers only 1² through k². Add (k + 1)² after substituting that old part.

Factor toward the target

Assume 1² + ⋯ + k² = k(k + 1)(2k + 1)/6. Then

1² + ⋯ + k² + (k + 1)² = k(k + 1)(2k + 1)/6 + (k + 1)²

= (k + 1)[k(2k + 1) + 6(k + 1)]/6

= (k + 1)(2k² + 7k + 6)/6 = (k + 1)(k + 2)(2k + 3)/6.

The final line is the original formula at n = k + 1. Factoring k + 1 early makes the remaining quadratic easier to recognize.

Prove the exact successor

An induction proof is not finished when the expression merely looks simpler. Write the target P(k + 1) beside the algebra and check that its factors match.

4 · Divisibility and growth

Choose a useful form of the hypothesis

For every n ≥ 1, the lecture proves that 3 divides 2²ⁿ − 1. The base n = 1 is 2² − 1 = 3. In the step, write the hypothesis as an integer equation: 2²ᵏ − 1 = 3m for some integer m.

Expose the multiple of three

2²⁽ᵏ⁺¹⁾ − 1 = 4·2²ᵏ − 1 = 4(2²ᵏ − 1) + 3 = 4(3m) + 3 = 3(4m + 1). Since 4m + 1 is an integer, the next expression is divisible by 3.

The inequality example starts later: P(n) is 2n + 1 < 2ⁿ for n ≥ 3. At n = 3, 7 < 8. If 2k + 1 < 2ᵏ, then

2(k + 1) + 1 = (2k + 1) + 2 < 2ᵏ + 2 < 2ᵏ + 2ᵏ = 2ᵏ⁺¹,

because k ≥ 3 makes 2 < 2ᵏ. State that extra comparison; it is part of the step, not a consequence of the induction hypothesis alone.

Divisibility is about an integer witness

To show 3 | x, express x = 3s for an integer s. Stopping at a numerical pattern such as several divisible cases does not prove the claim for every positive integer.

5 · Find the broken link

Why plausible induction proofs fail

A false sum with a valid-looking step

The slide proposes the false statement 1 + ⋯ + n = (n² + n + 1)/2. Its induction step can be manipulated into the successor expression because the incorrect right side carries the same extra constant at every n. But at n = 1, the left side is 1 and the right side is 3/2. There is no valid base case, so the step has nothing true from which to start.

The same-color cows argument

In a group of k + 1 cows, the argument takes the first k and last k cows, assumes each group has one color, and claims a shared cow connects their colors. For k = 1, the two one-cow groups are disjoint. There is no shared cow, so the argument fails exactly when trying to pass from one cow to two.

Locate the first invalid case

A picture or a convincing algebraic pattern cannot replace the logical checks. For an induction proof, test the base and the smallest use of the step before accepting the general claim.

6 · Use every earlier case

Strong induction and binary sums

Strong induction assumes P(1), P(2), …, P(k) together to prove P(k + 1), after a valid base. It reaches the same positive integers as ordinary induction, but its stronger-looking hypothesis is convenient when the next object depends on a smaller value other than k.

P(1)   ·   ∀k ≥ 1, [P(1) ∧ ⋯ ∧ P(k)] ⇒ P(k + 1)

Every positive integer is a sum of distinct powers of two

The base is 1 = 2⁰. For a target N = k + 1, either N itself is a power of two, or choose the largest 2ʲ < N and write N = 2ʲ + m. Then 1 ≤ m < 2ʲ and m ≤ k, so the strong induction hypothesis represents m with distinct powers below 2ʲ. Adding 2ʲ cannot repeat one of them.

For example, 54 = 32 + 16 + 4 + 2 = 2⁵ + 2⁴ + 2² + 2¹. Simply adding 1 to a representation of k may duplicate 2⁰, so the slide's first ordinary-induction attempt needs more work.

The remainder must be smaller

The proof invokes the hypothesis for m, so establish 1 ≤ m ≤ k first. Strong induction does not permit assuming the target case itself.

7 · A smaller denominator

Continued fractions use strong induction too

A finite continued fraction is built from an integer and repeated steps of the form q + 1/F, where q is an integer and F is a nonzero continued fraction. The lecture proves that every rational number has such a representation by inducting on a positive denominator.

Reduce the denominator

Write a rational number as a/d with d > 0. Integer division gives a = qd + r with 0 ≤ r < d. If r = 0, then a/d = q, already an integer continued fraction. If r > 0, then a/d = q + r/d = q + 1/(d/r). The rational d/r has the smaller positive denominator r, so the strong induction hypothesis supplies a continued fraction for it.

For example, 13/11 = 1 + 1/(11/2) = 1 + 1/(5 + 1/2). Each division step replaces the denominator by a smaller positive remainder until the process ends.

Induct on a well-founded quantity

The numerator need not shrink. The denominator does: 1 ≤ r < d. That strict decrease is what makes the recursive appeal valid.

8 · Match bases to dependencies

Recurrences need multiple starting cases

If the step for P(k + 1) uses P(k) and P(k − 1), prove two consecutive bases first. If it uses three preceding terms, prove three bases. More generally, a recurrence that reaches back d positions needs enough initial cases to make its first step legal.

A three-term sequence bound

The slides define a₁ = 1, a₂ = 1, a₃ = 3, and aₙ₊₃ = aₙ₊₂ + aₙ₊₁ + aₙ. They claim aₙ ≤ 2ⁿ⁻¹ for n ≥ 1. The first three values satisfy 1 ≤ 1, 1 ≤ 2, and 3 ≤ 4.

Assume the bound for indices k − 2, k − 1, and k. Then aₖ₊₁ ≤ 2ᵏ⁻³ + 2ᵏ⁻² + 2ᵏ⁻¹ = 7·2ᵏ⁻³ < 2ᵏ. This proves the next bound. The recurrence explains why one hypothesis alone would not suffice.

A two-term exact formula

Let s₀ = 0, s₁ = 4, and sₖ = 6sₖ₋₁ − 5sₖ₋₂ for k ≥ 2. The claimed formula is sₙ = 5ⁿ − 1. Both bases hold: 0 = 5⁰ − 1 and 4 = 5¹ − 1.

Assuming the formula at k − 1 and k gives sₖ₊₁ = 6(5ᵏ − 1) − 5(5ᵏ⁻¹ − 1) = 5ᵏ⁺¹ − 1. The step genuinely uses both preceding claims.

One base cannot start a two-term step

Checking s₀ alone leaves s₁ unavailable when the first recurrence step needs both s₀ and s₁. The number of bases follows from the dependencies in the recurrence.
