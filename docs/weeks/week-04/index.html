How do you prove every case, one existence and only one answer?

1 · Exhaustive partitions

Each branch must cover part of the whole

(p ∨ q) → r  ≡  (p → r) ∧ (q → r)

A proof by cases replaces one difficult argument with several simpler implications. The partition is valid only when every permitted input belongs to at least one branch.

Worked example: n² + n is even

  1. Let n be an arbitrary integer.
  2. If n = 2k, then n²+n = 2k(2k+1), which is even.
  3. If n = 2k+1, then n²+n = 2(2k²+3k+1), which is even.
  4. Every integer is even or odd, so the conclusion holds for all integers.
One integereven or oddTwo parity cases.
Two integersEE, OO, OE or EOFour ordered parity cases.
One real numberx > 0, x = 0 or x < 0Three order cases.
Two real numbersa > b, a = b or a < bTrichotomy.

Common mistake: convenient but incomplete cases

“Both even or both odd” omits mixed parity. Before doing algebra, state why the listed cases exhaust the domain.

2 · Remainders and congruence

Let the divisor choose the cases

When a conclusion concerns divisibility by k, classify integers by their possible remainders modulo k.

n ≡ r (mod k), where r ∈ {0, 1, …, k−1}

Worked example: 3 divides n³ − n

  1. If n = 3k, then n³−n = 3(9k³−k).
  2. If n = 3k+1, then n³−n = 3(9k³+9k²+2k).
  3. If n = 3k+2, then n³−n = 3(9k³+18k²+11k+2).
  4. The three remainder classes are exhaustive; every branch is divisible by three.

Pigeonhole principle

Five integers placed into the four remainder classes modulo four force at least two integers into the same class. Therefore at least two are congruent modulo four.

Common mistake: using parity for a modulo-three target

Even and odd track remainders modulo two. They do not expose all behaviour relevant to divisibility by three.

3 · A nested case proof

The absolute-value definition controls the branches

|x + y| ≤ |x| + |y|

Absolute value changes formula at zero, so begin with the four sign combinations for x and y. In mixed-sign branches, split again according to the sign of x+y.

Sign cases in the triangle-inequality proof
CaseKey substitutionsResult
x ≥ 0, y ≥ 0|x| = x, |y| = y, |x+y| = x+yEquality
x ≥ 0, y < 0|x| = x, |y| = −y; split on x+y|x+y| ≤ x−y
x < 0, y ≥ 0Symmetric mixed-sign argument|x+y| ≤ −x+y
x < 0, y < 0|x+y| = −x−yEquality

A reusable pattern

When a function is defined piecewise, use the boundaries in its definition to design cases. If another piecewise expression appears inside a branch, a justified subcase may be necessary.

Constructive witness on the unit circle

  1. Choose x = y = 1/√2.
  2. Both values are real and nonzero.
  3. x²+y² = 1/2+1/2 = 1.
  4. The candidate satisfies every condition, so the objects exist.

Non-constructive root from continuity

  1. Let f(x)=x⁴−3x+1, a continuous polynomial.
  2. f(0)=1 and f(1)=−1.
  3. The intermediate value theorem guarantees some c∈(0,1) with f(c)=0.
  4. The proof guarantees a root without calculating its exact value.

At least one value reaches the average

If every sᵢ were less than the average A, adding the inequalities would give s₁+···+sₙ < nA, contradicting the definition of A. Therefore some sᵢ ≥ A.

5 · Proving uniqueness

Exactly one means existence plus at-most-one

∃!x p(x)  means  [∃x p(x)] ∧ [∀a∀b, (p(a) ∧ p(b)) → a=b]

Label both parts. A candidate proves only existence. Comparing two arbitrary candidates proves at-most-one.

Unique real solution of x³ + 1 = 0

  1. Existence: x=−1 satisfies the equation.
  2. Uniqueness: let a and b be real solutions; then a³=b³.
  3. (a−b)(a²+ab+b²)=0. The second factor is positive for the negative roots.
  4. Therefore a−b=0, so a=b.

The only prime of the form n³ − 1 is 7

  1. Existence: 2³−1=7, which is prime.
  2. Factor n³−1=(n−1)(n²+n+1).
  3. For n>2, both factors exceed one, so the result is composite.
  4. Values n≤1 do not produce a positive prime; hence only n=2 remains.

Contrapositivea≠b ⇒ ¬p(a) ∨ ¬p(b)
Contradictionp(a) ∧ p(b) ∧ a≠b ⇒ ⊥

6 · Proof-writing discipline

Complete reasoning can still be concise

State the method, identify the domain and symbols, and justify the steps that carry the argument. Previously proved results may be cited without repeating their proofs.

Examples have different logical force
StatementSupporting exampleViolating example
UniversalDoes not prove itDisproves it
ExistentialProves itDoes not disprove it

Common errors to check before submission

Misreading the statement, proving a converse, treating examples as universal proof, changing what a symbol means, skipping a necessary case, jumping over a key step, or assuming the conclusion all break the logical chain.

A practical final check

Underline the hypothesis and target. Circle every witness. Number the cases and verify coverage. Name the exact contradiction. For uniqueness, locate both the existence and at-most-one paragraphs.
