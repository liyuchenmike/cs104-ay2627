1 · The language of proof

Definitions are working tools

A proof connects its hypothesis to its conclusion through statements that are already known, accepted or justified. Definitions turn descriptive words into algebraic forms that can be manipulated.

Roles played by mathematical statements
KindRoleWhat you do with it
Proposition or theoremA claim with a truth valueProve it from accepted facts
LemmaA supporting resultProve it, then reuse it
DefinitionFixes the meaning of a termUnpack it exactly
AxiomAn accepted starting ruleUse it within its conditions
Even integera = 2k for some k ∈ ℤ
Odd integera = 2k + 1 for some k ∈ ℤ
Divisibilitym | n ⇔ n = mq for some q ∈ ℤ
Congruencea ≡ b (mod m) ⇔ m | (a − b)

Closure keeps a proof inside its domain

The integers are closed under addition and multiplication, so expressions such as k + 1 and k² remain integers. They are not closed under division: 1 ÷ 2 is not an integer.

Common mistake: treating familiar algebra as unconditional

Cancellation by a requires a ≠ 0. A proof must establish that an inverse exists before it divides by a variable.

2 · Direct proof and counterexample

Follow the implication forward

Assume p  →  unpack definitions  →  apply known facts  →  reach q

For a universal proposition, take an arbitrary object from the stated domain. A final line should match the definition of the conclusion—not merely resemble it.

Worked example: an even square is divisible by four

  1. Let x be an arbitrary even integer.
  2. Then x = 2k for some k ∈ ℤ.
  3. x² = (2k)² = 4k².
  4. Because k² ∈ ℤ, this is four times an integer; therefore 4 | x².

Counterexample: the fastest valid disproof

To disprove ∀x ∈ S: p(x), find one permitted value c ∈ S for which p(c) is false. For a conditional, the example must make its hypothesis true and its conclusion false.

Disprove: if a² = b², then a = b

  1. Choose real numbers a = 1 and b = −1.
  2. The hypothesis is true because a² = b² = 1.
  3. The conclusion is false because 1 ≠ −1.
  4. The pair is a counterexample, so the universal claim is false.

3 · Proof by contrapositive

Use an equivalent direction when the direct route hides structure

p → q  ≡  ¬q → ¬p

The contrapositive reverses and negates both parts. It is equivalent to the original implication; the converse q → p and inverse ¬p → ¬q are not generally equivalent.

Worked example: if n² is even, then n is even

  1. Prove the contrapositive: if n is odd, then n² is odd.
  2. Write n = 2k + 1 for some k ∈ ℤ.
  3. n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1.
  4. The expression has odd form, so n² is odd. The original proposition follows by equivalence.

Read negated divisibility accurately

The original slide proposition says 3 ∤ mn → (3 ∤ m ∧ 3 ∤ n). Its contrapositive is (3 | m ∨ 3 | n) → 3 | mn, which is proved by considering the divisible factor.

A disjunction can be reshaped

p → (q ∨ r) is equivalent to (p ∧ ¬q) → r. Thus the zero-product property can be approached as: if ab = 0 and a ≠ 0, then b = 0. The nonzero assumption guarantees that 1/a exists.

Common mistake: reversing without negating

The contrapositive of “if n² is even, then n is even” is “if n is odd, then n² is odd.”

4 · Congruence and proof by contradiction

Assume the failed case and make its conflict visible

To prove p → q by contradiction, assume p ∧ ¬q. Derive an impossibility and identify the exact pair of incompatible statements.

Congruence translates into divisibility

a ≡ b (mod m) ⇔ m | (a − b) ⇔ a = b + mk for some k ∈ ℤ

For a fixed positive modulus, congruence is reflexive, symmetric and transitive. Adding the same integer to both sides also preserves congruence.

No integer n satisfies 2n ≡ 1 (mod 4)

  1. Assume for contradiction that 2n ≡ 1 (mod 4).
  2. Then 2n = 1 + 4k for some integer k.
  3. The left side is even, while the right side is odd.
  4. An integer cannot be both even and odd, so the assumption is impossible.

For positive x ≠ y, prove x/y + y/x > 2

  1. Assume instead that x/y + y/x ≤ 2.
  2. Since xy > 0, multiply without reversing the inequality: x² + y² ≤ 2xy.
  3. Rearrange to (x − y)² ≤ 0. Nonnegativity forces (x − y)² = 0.
  4. Then x = y, contradicting the hypothesis x ≠ y.

5 · Irrationality and proof synthesis

The √2 proof connects every idea

A rational number can be written as m/n for integers m,n with n > 0. We may choose the fraction in lowest terms, where numerator and denominator have no common factor greater than one.

Prove √2 is irrational

  1. Assume for contradiction that a positive r with r² = 2 is rational. Write r = m/n in lowest terms.
  2. m²/n² = 2, so m² = 2n². Thus m² is even, and the earlier contrapositive result gives that m is even.
  3. Write m = 2k. Substitution gives n² = 2k², so n is also even.
  4. Then 2 is a common factor of m and n, contradicting the choice of lowest terms. Therefore √2 is irrational.

Interpret the contradiction correctly

A quotient with a common factor can still be rational; 4/6 is rational. The contradiction is that a fraction chosen in lowest terms was forced to have a common factor.

Contrapositive

Assume ¬q
Derive ¬p
Conclude p → q

Contradiction

Assume p ∧ ¬q
Derive ⊥
Conclude p → q

Final application

r ∈ ℚ, s ∉ ℚ
Assume r+s ∈ ℚ
s = (r+s)−r ∈ ℚ: contradiction

Common mistake: writing “contradiction” without naming it

Point to the incompatible facts: x = y and x ≠ y; an integer is even and odd; or a lowest-terms pair shares factor 2.
