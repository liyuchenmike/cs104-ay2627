1 · Pairs that satisfy a condition

A relation is a subset of a Cartesian product

R ⊆ A × B   ·   a R b means (a, b) ∈ R

A relation from A to B records selected ordered pairs. A relation on A is a subset of A × A. Some source elements may have no partner, while others may have several. A function is a special relation in which every source element has exactly one output.

Divisibility as nine ordered pairs

Let A = {0, 1, 2}, B = {0, 1, 2, 3, 4}, and a R b mean a divides b. Then

R = {(0, 0), (1, 0), (1, 1), (1, 2), (1, 3), (1, 4), (2, 0), (2, 2), (2, 4)}.

In an arrow diagram, draw one arrow for each pair. Zero points only to zero, one points to every member of B, and two points to zero, two and four.

Why the course includes 0 | 0

The definition is a | b ⇔ b = ak for some integer k. Since 0 = 0k, zero divides zero under this definition. It divides no nonzero integer. This uses multiplication and does not define division by zero.

Other examples are {(x, y) ∈ ℝ² | x < y}, equality on ℝ, and {(a, b) ∈ ℤ² | n divides a − b} for a fixed positive modulus n. A verbal relation such as “is the father of” also gives ordered pairs; reversing a pair generally changes its meaning.

A relation need not be a function

The presence of (1, a) and (1, b), with a ≠ b, is valid for a relation. It violates the unique-output requirement for a function from the same source set.

2 · Coordinates that actually occur

Domain and range are projections

dom(R) = {a ∈ A | ∃b ∈ B, (a, b) ∈ R}
range(R) = {b ∈ B | ∃a ∈ A, (a, b) ∈ R}

For R = {(1, a), (1, b), (3, a)} from {1, 2, 3} to {a, b, c}, dom(R) = {1, 3} and range(R) = {a, b}. The unused source element 2 and unused target c do not appear in these projections.

Find both projections of an ellipse

Let S = {(x, y) ∈ ℝ² | 4x² + y² = 16}.

  1. A real y exists only if y² = 16 − 4x² ≥ 0, so −2 ≤ x ≤ 2. Conversely, every x in this interval has the real partner y = √(16 − 4x²). Thus dom(S) = [−2, 2].
  2. A real x exists only if 4x² = 16 − y² ≥ 0, so −4 ≤ y ≤ 4. Conversely, every such y has a partner x = √(16 − y²)/2. Thus range(S) = [−4, 4].

The endpoints belong because the other coordinate can be zero. For many x values there are two y partners, so the entire ellipse is not a function of x.

The ambient source set can be larger than dom(R)

For an arbitrary relation R ⊆ A × B, dom(R) may be a proper subset of A. For a function declared on A, every element of A must occur as an input.

3 · Three universal conditions

Test each property separately

Properties of R on A
PropertyRequired statementCounterexample
Reflexive∀x ∈ A, (x, x) ∈ ROne x ∈ A with a missing loop.
Symmetric(x, y) ∈ R implies (y, x) ∈ RA pair present whose reverse is absent.
Transitive(x, y), (y, z) ∈ R imply (x, z) ∈ RA two-step path with no required direct pair.

In the last two rows the variables range over all of A. They need not be distinct. For example, (a, b) and (b, a) form a two-step path that requires (a, a) under transitivity.

Divisibility on ℤ

Reflexive: a = a · 1, so a | a, including a = 0.

Not symmetric: 1 | 2 but 2 ∤ 1.

Transitive: if b = ak and c = bℓ for integers k, ℓ, then c = a(kℓ), so a | c. No division by a is needed.

Integer difference on ℚ

Define a T b ⇔ a − b ∈ ℤ for rational a, b. Reflexivity follows from a − a = 0. Symmetry follows from b − a = −(a − b). Transitivity follows from a − c = (a − b) + (b − c). Integers are closed under negation and addition.

Symmetry and transitivity do not imply reflexivity

The tempting proof starts with x R y, reverses it, then chains the two pairs to obtain x R x. The gap is the assumption that every x has such a y.

Take A = {1, 2} and R = {(1, 1)}. Every pair has its reverse, and every available two-step path has its direct pair. Yet (2, 2) is missing. The empty relation on a nonempty set is another counterexample: symmetry and transitivity hold vacuously.

4 · Equivalence and its classes

Equivalence means agreement under a chosen relation

An equivalence relation is reflexive, symmetric and transitive. Related elements may be different objects: 1 and 4 are distinct but equivalent modulo 3.

Familiar relations on their stated domains
RelationReflexiveSymmetricTransitiveEquivalence
< on ℝNoNoYesNo
= on ℝYesYesYesYes
Divisibility on ℤYesNoYesNo
Congruence modulo n > 0 on ℤYesYesYesYes

When each student has one recorded midterm grade, “has the same grade as” is an equivalence relation: equality of grades is reflexive, symmetric and transitive.

[a]R = {x ∈ A | (x, a) ∈ R}

The equivalence class of a collects all elements related to a. The subscript identifies the relation; we omit it when the relation is clear. A class contains elements of A, while the relation contains ordered pairs.

Five representatives, two classes

For S = {a, b, c, d, e}, let R contain every ordered pair within {a, b} and every ordered pair within {c, d, e}, with no pairs between the groups. Then [a] = [b] = {a, b} and [c] = [d] = [e] = {c, d, e}. There are two distinct classes.

Likewise, if David and Mary both have grade A, their classes under the same-grade relation are equal: each is the set of all students with grade A. This does not assert David = Mary.

Do not assume class properties for an arbitrary relation

You can collect the neighbours of an element for any relation. To call these equivalence classes with the properties below, first establish that the relation is an equivalence relation.

5 · Classes and partitions

Classes are equal or disjoint

a ∈ [a]   ·   a R b ⇔ [a] = [b]
not a R b ⇔ [a] ∩ [b] = ∅

Why related elements have equal classes

  1. Suppose a R b and take x ∈ [a]. Then x R a and a R b, so transitivity gives x R b. Thus [a] ⊆ [b].
  2. Symmetry gives b R a. The same argument proves [b] ⊆ [a], so the classes are equal.
  3. Conversely, if [a] = [b], reflexivity gives a ∈ [a], hence a ∈ [b], which means a R b.

Why one shared element forces equality

If x belongs to both [a] and [b], then x R a and x R b. Symmetry gives a R x; transitivity yields a R b. The previous result gives [a] = [b]. Therefore distinct classes have empty intersection.

Conversely, disjoint classes cannot have related representatives: related representatives would give equal classes, and each class is nonempty because it contains its representative.

A partition of A is a collection of nonempty, pairwise disjoint subsets whose union is A. Equivalence classes give a partition: reflexivity ensures coverage and nonemptiness, and the argument above ensures disjointness. Conversely, a partition defines an equivalence relation by placing a R b exactly when a and b lie in the same block.

Count equivalence relations on {a, b, c}

The five partitions are:

  1. {{a}, {b}, {c}}
  2. {{a, b}, {c}}
  3. {{a, c}, {b}}
  4. {{b, c}, {a}}
  5. {{a, b, c}}

Each gives one equivalence relation, so there are five. For a block C, include every pair in C × C. Reordering the blocks does not create another partition.

Finitely many classes can each be infinite

Congruence modulo 3 has three classes, each containing infinitely many integers. Other equivalence relations can have infinitely many classes; equality on ℤ has one singleton class for each integer.

6 · Arithmetic with classes

Calculate without depending on the representative

For a positive integer n, define [a]ₙ = {x ∈ ℤ | n divides x − a}. Modulo 3, the three distinct classes are

  • [0]₃ = {…, −6, −3, 0, 3, 6, …};
  • [1]₃ = {…, −5, −2, 1, 4, 7, …};
  • [2]₃ = {…, −4, −1, 2, 5, 8, …}.

For example, [−1]₃ = [2]₃. Every integer has exactly one remainder in {0, 1, 2} upon division by 3, so these classes cover ℤ without overlap.

[a]ₙ ⊕ [b]ₙ = [a + b]ₙ   ·   [a]ₙ ⊗ [b]ₙ = [ab]ₙ

Different representatives, the same answer

Modulo 5, [1]₅ = [6]₅ and [3]₅ = [8]₅. Using 1 and 3 gives sum [4]₅ and product [3]₅. Using 6 and 8 gives sum [14]₅ = [4]₅ and product [48]₅ = [3]₅.

Why this always works: if a ≡ b and c ≡ d (mod n), then n divides (a − b) + (c − d), so a + c ≡ b + d. Also ac − bd = a(c − d) + d(a − b), a sum of multiples of n. Hence ac ≡ bd. Repeated multiplication gives aᵐ ≡ bᵐ for every positive integer m.

These proofs establish that the class operations are well-defined: changing representatives never changes the resulting class. Agreement in one numerical example alone would not prove this universal claim.

Derive the divisibility test for nine

Since 10 ≡ 1 (mod 9), every decimal place value 10ᵏ is congruent to 1. If N = dₖ10ᵏ + … + d₁10 + d₀, then N ≡ dₖ + … + d₁ + d₀ (mod 9). Thus N and its digit sum have the same remainder modulo 9.

For 7319, the sum is 7 + 3 + 1 + 9 = 20 ≡ 2 (mod 9). Therefore 7319 is not divisible by 9, and its remainder is 2. For comparison, 729 has digit sum 18, so 9 divides 729.

Equal classes are not equal integers

[7319]₉ = [20]₉ is true, while 7319 = 20 is false. Keep the brackets or the congruence symbol when reducing a number modulo n.
