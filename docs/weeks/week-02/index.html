1 · Predicates and quantified statements

A variable leaves a sentence open

A predicate contains one or more variables. It becomes a statement only after its variables are replaced by values or bound by quantifiers. If p(n) means “n is odd,” then p(2) is false and p(3) is true.

Always identify the domain

The truth of a quantified statement depends on which values are allowed. ∃x: x² = 2 is false over the integers but true over the real numbers. A valid witness must belong to the stated domain.

Two quantifiers, two burdens of proof

Universal∀x ∈ D: p(x)Every allowed x makes p(x) true.
Existential∃x ∈ D: p(x)At least one allowed x makes p(x) true.
What establishes or refutes a one-variable quantified claim?
ClaimTo establishTo refute
∀x: p(x)Justify p(x) for an arbitrary xFind one x with ¬p(x)
∃x: p(x)Find one x with p(x)Show ¬p(x) for every x

Worked example: witness or counterexample?

Over the real numbers, evaluate ∀x: x² > 0.

  1. The claim is universal, so search for an allowed counterexample.
  2. Choose x = 0.
  3. Substitution gives 0² > 0, which is false.
  4. One counterexample is enough: the universal statement is false.

Universal conditional statements

A sentence such as “Every square is a rectangle” has form ∀x: Square(x) → Rectangle(x). It does not say that every object is a square; it says that whenever an object satisfies the hypothesis, it also satisfies the conclusion.

Common mistake: forgetting a hidden quantifier

Mathematical writing may say “If x is real, then x² ≥ 0” without displaying ∀x. When the sentence is intended as a general rule, the universal quantifier is understood. Make it explicit before analysing the claim.

2 · Negating quantified statements

Negation switches the quantifier

To make “every x works” false, at least one x must fail. To make “some x works” false, every x must fail. This gives the two fundamental equivalences:

¬(∀x: p(x)) ≡ ∃x: ¬p(x)    and    ¬(∃x: p(x)) ≡ ∀x: ¬p(x)

Negate meaning, not just words

Negate: “Some computer hackers are over 40.”

  1. Write the form ∃x: Hacker(x) ∧ Over40(x).
  2. Switch existence to universality.
  3. Negate the predicate: every hacker is not over 40.
  4. In natural language: All computer hackers are 40 or under.

Negating a universal conditional

An implication fails only when its hypothesis is true and its conclusion false:

¬(∀x: p(x) → q(x)) ≡ ∃x: p(x) ∧ ¬q(x)

The negation of “Every program over 100,000 lines contains a bug” is “There is a program over 100,000 lines that contains no bug.”

Related quantified conditionals

Original∀x: p(x) → q(x)
Contrapositive∀x: ¬q(x) → ¬p(x)Equivalent to the original.
Converse∀x: q(x) → p(x)Not generally equivalent.
Inverse∀x: ¬p(x) → ¬q(x)Not generally equivalent.

In ∀x: p(x) → q(x), p is a sufficient condition for q, and q is a necessary condition for p. “p only if q” also means p → q.

Common mistake: replacing “not every” with “none”

“Not every politician is honest” means at least one politician is not honest. It does not claim that no politician is honest. The negation of a universal claim is an existential counterexample.

3 · Statements with multiple quantifiers

Order controls dependency

For a predicate p(x,y), both variables must be bound. Matching quantifiers can change places without changing meaning, but mixed quantifiers usually cannot.

Every pair∀x ∀y: p(x,y)p holds for every x–y combination.
At least one pair∃x ∃y: p(x,y)One successful x–y pair is enough.
Dependent witness∀y ∃x: p(x,y)x may be chosen after y and may depend on it.
Fixed witness∃x ∀y: p(x,y)One x must work for every y.

Worked example: x + y = 0 over the reals

Compare ∀y ∃x: x + y = 0 with ∃x ∀y: x + y = 0.

  1. For an arbitrary y, choosing x = −y makes the equation true. The first statement is true.
  2. The second statement requires one fixed x before y is known.
  3. Whatever x is chosen, selecting y = 1 − x makes x + y = 1.
  4. No fixed x works for every y, so the second statement is false.

Read quantifiers as a choice game

In ∀y ∃x, an opponent selects y first and you respond with x. In ∃x ∀y, you commit to x first and the opponent may then test every y. This makes the dependency difference visible.

Negate from left to right

¬(∀y ∃x: p(x,y)) ≡ ∃y ∀x: ¬p(x,y)
¬(∃x ∀y: p(x,y)) ≡ ∀x ∃y: ¬p(x,y)

The quantifier order stays in place while each quantifier switches. The final predicate is negated only after the negation has moved through every quantifier.

4 · Arguments with quantified statements

Instantiate the rule before applying it

A universal rule applies to any eligible particular object. Once instantiated, familiar propositional rules determine whether the inference is valid.

Universal direct implication

∀x: p(x) → q(x)
p(a)
∴ q(a)

Universal contrapositive

∀x: p(x) → q(x)
¬q(a)
∴ ¬p(a)

Universal transitivity

∀x: p(x) → q(x)
∀x: q(x) → r(x)
∴ ∀x: p(x) → r(x)

Use a diagram to search for a countermodel

Argument: “All humans are mortal. Felix is mortal. Therefore, Felix is human.”

  1. Draw the human set entirely inside the mortal set.
  2. Place Felix in the mortal set but outside the human subset.
  3. Both premises are true in this arrangement.
  4. The conclusion is false, so the arrangement is a countermodel and the argument is invalid.
Converse error∀x: p(x) → q(x)
q(a)
∴ p(a)Membership in the larger q-set does not force membership in the p-subset.
Inverse error∀x: p(x) → q(x)
¬p(a)
∴ ¬q(a)Failing p does not prevent q from holding for another reason.

Common mistake: checking whether the conclusion is actually true

Validity asks whether the premises force the conclusion. An invalid argument can have a true conclusion; a valid argument can discuss fictional objects. Search for a possible countermodel, not for agreement with real-world facts.
