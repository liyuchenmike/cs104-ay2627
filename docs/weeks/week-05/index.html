1 · Membership and representation

A set needs a precise membership test

A set is a well-defined collection of objects. Roster notation lists its elements, as in {−2, 2}. Set-builder notation specifies a domain and a condition. Repeated elements and the order of a roster do not change a set.

{x ∈ U | p(x)} = the objects x in U for which p(x) is true

Three descriptions, three membership tests

  • Integer solutions of x² = 4: {x ∈ ℤ | x² = 4} = {−2, 2}.
  • Reciprocals of positive integers: {1/n | n ∈ ℤ⁺} = {1, 1/2, 1/3, …}. Zero is not a member, although these numbers approach zero.
  • Positive real numbers below 10: {x ∈ ℝ | 0 < x < 10} = (0, 10). Both endpoints are excluded.

The odd integers can be written {2k + 1 | k ∈ ℤ}. Letting k range over all integers includes negative odd numbers. Restricting k to nonnegative integers would change the set.

Membership is not containment

For A = {1, 2}, write 1 ∈ A and {1} ⊆ A. The first compares an element with a set; the second compares two sets. The empty set ∅ has zero elements, while {∅} and {0} each have one.

2 · Containment and equality

Translate containment into an implication

A ⊆ B ⇔ ∀x ∈ U, (x ∈ A → x ∈ B)
A ⊈ B ⇔ ∃x ∈ U, (x ∈ A ∧ x ∉ B)

To prove a subset claim, take an arbitrary element of the left set and show that it satisfies the right set’s definition. To refute it, exhibit one element on the left that is missing on the right.

Multiples of six are even

Let A = {x ∈ ℤ | 6 | x} and B = {x ∈ ℤ | x is even}. For arbitrary x ∈ A, write x = 6m = 2(3m) with m ∈ ℤ. Since 3m is an integer, x is even. Therefore A ⊆ B.

Divisibility of a square does not transfer unchanged

Let C = {x ∈ ℤ | 4 | x²} and D = {x ∈ ℤ | 4 | x}. The witness 2 belongs to C because 4 | 2², but 2 ∉ D because 4 ∤ 2. Thus C ⊈ D.

In fact C is exactly the even integers. If x = 2k, then x² = 4k². Conversely, an odd x = 2k + 1 has square 4(k² + k) + 1, which is not divisible by four. This proves both inclusions needed for equality.

A = B requires A ⊆ B and B ⊆ A. A proper subset, written A ⊂ B in this course, additionally requires A ≠ B. For example, D ⊂ C: every multiple of four belongs to C, while 2 ∈ C − D.

Why ∅ ⊆ A for every set A

A counterexample would have to belong to ∅ and lie outside A. No object belongs to ∅, so none exists. Equivalently, the membership implication is vacuously true. Also, A ⊆ A always holds; ordinary containment does not require two different sets.

3 · Set operations and identities

Use logic to calculate and prove

Operations for A, B ⊆ U
SetMembership condition
A ∩ Bx ∈ A and x ∈ B
A ∪ Bx ∈ A or x ∈ B, including both
Aᶜx ∈ U and x ∉ A
A − Bx ∈ A and x ∉ B

Compute within a stated universe

Let U = {1, 2, 3, 4, 5}, A = {1, 2, 3}, and B = {3, 4}. Then A ∩ B = {3}, A ∪ B = {1, 2, 3, 4}, Aᶜ = {4, 5}, A − B = {1, 2}, and B − A = {4}.

The laws mirror propositional logic: union and intersection are idempotent, commutative, and associative; each distributes over the other. Double complementation gives (Aᶜ)ᶜ = A.

(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ   ·   (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ

Prove A − B = A ∩ Bᶜ by membership

For arbitrary x ∈ U, x ∈ A − B exactly when x ∈ A and x ∉ B; this is equivalent to x ∈ A and x ∈ Bᶜ, or x ∈ A ∩ Bᶜ. The equivalences establish both inclusions.

Prove an identity using set algebra

(A ∪ B) − C = (A ∪ B) ∩ Cᶜ = (A ∩ Cᶜ) ∪ (B ∩ Cᶜ) = (A − C) ∪ (B − C).

The steps use the difference identity, distribution, and the difference identity again.

Check the universe and the order

A complement changes when U changes. Difference is generally not commutative: A − B and B − A select different regions. A Venn diagram helps discover a law, but a proof should justify membership or cite valid identities.

4 · Ordered pairs

A Cartesian product creates pairs

A × B = {(a, b) | a ∈ A and b ∈ B}

For A = {1, 2, 3} and B = {u, v}, A × B has six elements: (1, u), (1, v), (2, u), (2, v), (3, u), and (3, v). For finite sets, |A × B| = |A||B|. The notation A² means A × A.

Order matters: (a, b) = (c, d) requires a = c and b = d. Products are not commutative in general, although A × B can equal B × A in special cases such as A = B. Similarly, (a, b) differs from (b, a) when a ≠ b.

Interpret subsets of the plane

[1, 3] × [2, 5] is the closed rectangle with 1 ≤ x ≤ 3 and 2 ≤ y ≤ 5. By contrast, x² + y² = 1 defines the unit circle, while x² + y² ≤ 1 defines the closed disk. The origin is in the disk but outside the circle.

A × (B ∪ C) = (A × B) ∪ (A × C)

Prove distribution with an arbitrary pair

  1. Take (x, y) ∈ A × (B ∪ C). Then x ∈ A and either y ∈ B or y ∈ C. Hence the pair belongs to (A × B) ∪ (A × C).
  2. Conversely, a pair in that union belongs to one of the two products. Its first coordinate is in A, and its second lies in B or C, so it belongs to A × (B ∪ C).

The same pattern holds for intersection and difference, and for a fixed factor on the right: (A − B) × C = (A × C) − (B × C). Keep each coordinate in its original position.

5 · A rule with a domain and codomain

Every input must have exactly one output

A function f: A → B assigns every a ∈ A exactly one element f(a) ∈ B. A is the domain; B is the codomain. Several inputs may share an output, and some codomain elements may remain unused.

Does the proposed rule define a function?
Rule and declared setsDecision
sin x, ℝ → ℝYes: every real input has one real output.
1/x, ℝ → ℝNo: zero has no output. Restricting the domain to ℝ − {0} repairs this.
Both ±√x, ℝ⁺ → ℝNo: each positive input has two proposed outputs.
x², ℝ → ℝYes: shared outputs such as f(2) = f(−2) are allowed.

The image of a is f(a). A preimage of b is an a in the domain satisfying f(a) = b. For squaring on ℝ, the preimage set of 4 is {−2, 2}, while the preimage set of −1 is empty. For sine on ℝ, the preimages of 0 are {kπ | k ∈ ℤ}.

Floor and ceiling, including negative inputs

⌊x⌋ is the greatest integer at most x; ⌈x⌉ is the least integer at least x. Thus ⌊2.74⌋ = 2, ⌈2.74⌉ = 3, ⌊−1.9⌋ = −2, and ⌈−1.9⌉ = −1. Both send 3 to 3.

Useful tests: ⌊x⌋ = n ⇔ n ≤ x < n + 1, and ⌈x⌉ = n ⇔ n − 1 < x ≤ n. Floor is not truncation toward zero.

Range versus codomain

range(f) = {f(x) | x ∈ A} consists of outputs actually reached. It is always a subset of B. For x²: ℝ → ℝ, the range is [0, ∞); for sin: ℝ → ℝ, it is [−1, 1]. To prove an exact range, show outputs cannot leave it and every element of it is reached.

6 · Injection, surjection and bijection

Separate uniqueness from coverage

Proof obligations for f: A → B
PropertyWhat to proveHow to refute it
InjectiveFor x, y ∈ A, f(x) = f(y) implies x = y.Find distinct x, y ∈ A with equal outputs.
SurjectiveFor every b ∈ B, find a ∈ A with f(a) = b.Find b ∈ B that no input reaches.
BijectiveProve both injection and surjection.Refute either requirement.

f(x) = 5x + 3 is a bijection ℝ → ℝ

Injection: if 5x + 3 = 5y + 3, subtract 3 and divide by 5 to obtain x = y.

Surjection: choose arbitrary b ∈ ℝ. Let a = (b − 3)/5. Then a ∈ ℝ and f(a) = 5(b − 3)/5 + 3 = b. Every target is reached.

Change the sets, change the classification

g(x) = x² + 1 is neither injective nor surjective as a function ℝ → ℝ: g(2) = g(−2) = 5, and −2 has no preimage.

As a function ℝ⁺ → (1, ∞), the same formula is bijective. Equal squares of positive inputs force equal inputs. For every b > 1, the positive input a = √(b − 1) satisfies g(a) = b.

A solved equation is only a candidate

In a surjection proof, the constructed preimage must belong to the domain and must map to the arbitrary target. For example, 5x + 3 is not onto ℤ as a function ℤ → ℤ: the target 4 would require x = 1/5, outside the domain.

In terms of preimages, injective means at most one, surjective means at least one, and bijective means exactly one for every element of the codomain. These are separate from the function requirement of exactly one image per input.
