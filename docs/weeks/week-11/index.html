Week 11 · Recursion

How do a few starting values determine a whole sequence?

Model problems recursively, then turn second-order recurrence rules into explicit formulas using characteristic roots.

  • model rabbits, Hanoi moves and staircase paths;
  • recognize a second-order linear homogeneous rule;
  • derive and solve its characteristic equation;
  • fit distinct-root and repeated-root formulas to starting values.

1 · Start and continue

A recurrence needs an initial condition

A recursive sequence is determined by starting value(s) and a rule for later terms. For example, an arithmetic sequence with a₀ = c and fixed difference d obeys aₙ = aₙ₋₁ + d for n ≥ 1. From the same starting value, a geometric sequence with ratio r obeys aₙ = r aₙ₋₁. Without c, either rule describes many sequences.

a₀ = c, aₙ = aₙ₋₁ + d ⇒ aₙ = c + nd
a₀ = c, aₙ = r aₙ₋₁ ⇒ aₙ = crⁿ

Factorial is recursive too

Start with 0! = 1, then define n! = n(n − 1)! for n ≥ 1. Thus 4! = 4·3! = 4·3·2·1 = 24. The recurrence says how to obtain a term; the initial condition stops the backward chain.

Count how far the rule looks back

A rule that uses both aₙ₋₁ and aₙ₋₂ normally needs two starting values. A single first term does not determine the next one.

2 · Two earlier terms

Fibonacci numbers model the rabbit population

This lecture defines f₀ = f₁ = 1 and fₙ = fₙ₋₁ + fₙ₋₂ for n ≥ 2. Its first values are 1, 1, 2, 3, 5, 8, 13. This indexing is deliberate: some books instead begin with 0, 1, shifting every later label by one.

From rabbit rules to an equation

Let rₙ be the number of pairs alive at the end of month n. No pair dies, so the current total is last month's total plus newborn pairs. Pairs born this month come from pairs old enough to reproduce, counted two months earlier. Hence rₙ = rₙ₋₁ + rₙ₋₂, with r₀ = r₁ = 1.

Under the slide's idealized rules, r₁₂ = 233 pairs after twelve months. That is 466 individual rabbits. The unit matters when answering “how many rabbits?”

Do not silently change the first terms

Using the 0, 1 convention while keeping this lecture's indices would give the wrong month count and the wrong closed formula later.

3 · Solve a smaller copy

The Tower of Hanoi doubles its work

To transfer k disks without putting a larger disk on a smaller one, first move the top k − 1 disks to the spare pole, then move the largest disk once, then transfer the smaller tower onto it. Let mₖ be the minimum moves. The first and last stages each cost mₖ₋₁, giving the recurrence below.

m₁ = 1; mₖ = 2mₖ₋₁ + 1 for k ≥ 2
mₖ = 2ᵏ − 1

Unroll and check

The first values are m₁ = 1, m₂ = 3, m₃ = 7 and m₄ = 15. The pattern is 1 + 2 + 4 + ⋯ + 2ᵏ⁻¹ = 2ᵏ − 1. Substituting 2ᵏ⁻¹ − 1 into the recurrence produces 2(2ᵏ⁻¹ − 1) + 1 = 2ᵏ − 1. For 30 disks, the minimum is 1,073,741,823 moves.

The middle move is essential

Writing 2mₖ₋₁ omits the one move of the largest disk. The two smaller transfers also cannot be skipped, because the largest disk must first be uncovered and then have the tower rebuilt above it.

4 · Split by the last step

Climbing stairs has a Fibonacci count

Suppose each move climbs one or two stairs. A path to stair n ends in exactly one of two ways: a one-stair move after a path to n − 1, or a two-stair move after a path to n − 2. These classes are disjoint, so their counts add.

s₀ = 1, s₁ = 1; sₙ = sₙ₋₁ + sₙ₋₂ for n ≥ 2

Three stairs

The three routes are 1 + 1 + 1, 1 + 2 and 2 + 1. Thus s₃ = 3. The one empty route for zero stairs supplies s₀ = 1; s₂ = 2, s₃ = 3 and s₄ = 5 follow. With this lecture's indexing, sₙ = fₙ.

Count paths, not the number of moves

The route 1 + 2 and the route 2 + 1 are different orders and count separately. The empty route for zero stairs is one valid starting case, not zero ways.

5 · From rule to formula

Recognize the characteristic equation

A second-order linear homogeneous recurrence with constant coefficients has the form aₖ = A aₖ₋₁ + B aₖ₋₂, where A and B are fixed real numbers, B ≠ 0, and k ≥ 2. It looks back two terms; the earlier values are multiplied by constants and added, with no extra independent term.

Classify before solving

The rule eₖ = 2eₖ₋₂ fits with A = 0 and B = 2. A rule involving aₖ₋₃ is third-order; a squared preceding term is nonlinear; a trailing “+ 1” is nonhomogeneous; and a coefficient involving k is not constant. The root method below is for the stated family.

Try a power sequence aₖ = tᵏ with t ≠ 0. Substitute it into the rule and divide by tᵏ⁻². A solution must satisfy:

tᵏ = Atᵏ⁻¹ + Btᵏ⁻² ⇒ t² − At − B = 0.

Keep the sign on B

The recurrence has +B aₖ₋₂ on the right. Moving it left produces −B in the characteristic polynomial.

6 · Two different roots

Combine power sequences

For aₖ = aₖ₋₁ + 2aₖ₋₂, the characteristic equation is t² − t − 2 = (t − 2)(t + 1) = 0. Its roots 2 and −1 give separate solutions 2ᵏ and (−1)ᵏ. Because the recurrence is linear and homogeneous, any constant combination is also a solution.

If r ≠ s are roots: aₖ = C rᵏ + D sᵏ.
a₀ = C + D; a₁ = Cr + Ds.

Initial values select one combination

The roots specify the two building blocks but do not fix C and D. Given a₀ and a₁, solve the two displayed equations. Distinct roots ensure a unique pair of constants. For the example above, aₖ = C·2ᵏ + D·(−1)ᵏ; every choice of C and D follows the rule, but only one choice fits any given pair of first terms.

A root is not an initial value

Finding roots ends the characteristic-equation step. The initial conditions still have to be imposed before you have the formula for the particular sequence.

7 · Fit the Fibonacci bases

An explicit formula for this Fibonacci sequence

The Fibonacci rule fₖ = fₖ₋₁ + fₖ₋₂ has characteristic equation t² − t − 1 = 0. Write its roots as φ = (1 + √5)/2 and ψ = (1 − √5)/2. Distinct roots give fₖ = Cφᵏ + Dψᵏ. The bases f₀ = f₁ = 1 yield C + D = 1 and Cφ + Dψ = 1.

C = φ/√5, D = −ψ/√5
fₖ = (φᵏ⁺¹ − ψᵏ⁺¹)/√5

Check the shift

At k = 0, φ − ψ = √5, so the formula gives f₀ = 1. At k = 1, φ² − ψ² = (φ − ψ)(φ + ψ) = √5, giving f₁ = 1. The exponent k + 1 is essential for the one-and-one convention on the slides.

Do not import an unshifted formula

The often-seen formula (φᵏ − ψᵏ)/√5 begins with zero at k = 0. It solves the same recurrence with different initial values, so it is not this deck's fₖ.

8 · One root twice

A repeated root needs a second kind of term

If t² − At − B has a repeated real root r, the general solution is (C + Dk)rᵏ. The extra factor k makes a second independent solution; two copies of rᵏ would give only one adjustable constant. The lecture's example starts with b₀ = 1, b₁ = 3 and bₖ = 4bₖ₋₁ − 4bₖ₋₂.

Fit the repeated-root example

Its characteristic polynomial is t² − 4t + 4 = (t − 2)², so write bₖ = (C + Dk)2ᵏ. At k = 0, C = 1. At k = 1, 3 = 2(C + D), so D = 1/2. Therefore bₖ = 2ᵏ(1 + k/2). At k = 2 this gives 8, matching 4·3 − 4·1.

Check which root case applies

Use C rᵏ + D sᵏ only for distinct roots; use (C + Dk)rᵏ for a repeated real root. The slide closes by asking about no real roots, which is a further complex-root case beyond these two formulas.
